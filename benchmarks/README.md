# Benchmarks

Our experiments employ the following six routing cases:

`C2IO1`, `C8IO1`, `C4M4`, `G1M4`, `C12IO1`, and `G2M8`.

All cases are derived from [CIT-Bench](https://github.com/tjwangyj/CIT-Bench/), an open-source benchmark suite for chiplet-based advanced packaging. The input format is:

- `<CASE>_grid_layout.json`: grid pitch, grid dimensions, microbumps on top layer and C4 bumps on bottom layer;
- `<CASE>_netlist.json`: two-terminal signal nets that reference the bumps.

This file format originates from Problem 4 in [the openDACS Open-Source EDA and IC Contest](https://competition.openatom.tech/competitionInfo?id=e975263fde6bdf33f257d623e9477d52). `C2IO1`, `C8IO1`, `C4M4`, and `G1M4` are directly taken from [the public benchmark of the contest](https://atomgit.com/opendacs2025_competition_4/OpenDACS2025-contest4-Benchmark). `C12IO1` and `G2M8` are generated by us from CIT-Bench following the same format.

The statistics of these cases are listed as follows:

| case | \#chiplets | grid pitch (μm) | grid width $\times$ height | \#nets (\#D2D nets + \#Fanout nets) | \#microbumps | \#C4 bumps |
|---|---:|---:|---:|---:|---:|---:|
| C2IO1 | 3 | 5 | 4,560 $\times$ 3,840 | 700 (140 + 560) | 840 | 560 |
| C8IO1 | 9 | 5 | 9,880 $\times$ 6,160 | 3,300 (560 + 2,740) | 3,860 | 2,740 |
| C4M4 | 8 | 1 | 33,000 $\times$ 36,600 | 9,636 (9,284 + 352) | 18,920 | 352 |
| G1M4 | 5 | 1 | 37,000 $\times$ 28,000 | 6,933 (6,788 + 145) | 13,721 | 145 |
| C12IO1 | 13 | 5 | 12,200 $\times$ 6,160 | 3,768 (888 + 2,880) | 4,656 | 2,880 |
| G2M8 | 10 | 1 | 57,750 $\times$ 52,510 | 17,976 (17,632 + 344) | 35,608 | 344 |
